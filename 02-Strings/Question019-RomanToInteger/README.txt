Convert a Roman numeral string to an integer.

Roman numeral symbols:
  I=1, V=5, X=10, L=50, C=100, D=500, M=1000

Subtraction rule: when a smaller symbol precedes a larger one, subtract it.
  IV=4, IX=9, XL=40, XC=90, CD=400, CM=900

Restrictions:
- Do not use LINQ
- O(n) time complexity
- Input is always valid (range 1 to 3999)
