Given an array with only values 0, 1, and 2, sort it in-place so
all 0s come first, then all 1s, then all 2s.
This is known as the Dutch National Flag problem.

Restrictions:
- Single pass O(n) solution required
- O(1) extra space
- Do not use Array.Sort() or LINQ
- Do not count and rewrite (three-pointer approach required)
