You have two sorted integer arrays nums1 and nums2.
nums1 has a length of m + n, where the first m elements hold data
and the last n elements are zero-padded placeholders.
Merge nums2 into nums1 in sorted order, in-place.

Restrictions:
- Do not use LINQ
- Do not allocate a new result array
- O(m + n) time complexity
- O(1) extra space
