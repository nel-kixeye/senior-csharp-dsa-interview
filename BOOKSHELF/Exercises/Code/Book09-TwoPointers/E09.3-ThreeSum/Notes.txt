WHAT I WAS MISSING - de-duplication, in TWO places
  SITE A  if (i > 0 && nums[i] == nums[i-1]) continue;
          An equal fixed value re-runs the identical scan.
          [-4,-1,-1,0,1,2] found [-1,0,1] once per '-1'.

  SITE B  after recording and advancing:
              while (lo < hi && nums[lo] == nums[lo-1]) lo++;

          [-2,0,0,2,2] found [-2,0,2] twice from a SINGLE fixed element.
          Implementing only SITE A still fails this case.

  Advance FIRST, then compare against the value just consumed. Comparing
  before advancing is off by one.
