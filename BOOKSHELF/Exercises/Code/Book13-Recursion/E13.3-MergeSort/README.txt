Merge Sort

Implement merge sort on an integer array.

- Constraints: up to 10⁵ elements. Do not call a library sort.
- Target: O(n log n) time, O(n) space, stable.
- Edge cases: empty; single element; already sorted; reverse sorted; all
  duplicates.
