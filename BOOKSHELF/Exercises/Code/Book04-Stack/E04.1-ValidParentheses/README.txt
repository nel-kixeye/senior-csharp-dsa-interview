Valid Parentheses

Given a string of (), [], {}, determine whether it is correctly balanced
and properly nested.

- Constraints: up to 10⁴ characters, brackets only.
- Target: O(n) time, O(n) space.
- Edge cases: empty string (valid); "("; ")"; "([)]" (wrong nesting);
  "(((".
