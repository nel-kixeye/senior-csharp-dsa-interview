Climbing Stairs

You can climb 1 or 2 steps at a time. How many distinct ways to reach step n?

- Constraints: 1 <= n <= 45.
- Target: O(n) time, O(1) space.
- Edge cases: n = 1; n = 2; verify against Fibonacci for n = 10 (89).
