Count Primes

Count the primes strictly less than n.

- Constraints: n up to 5·10⁶. A per-number primality test is too slow.
- Target: O(n log log n) time, O(n) space.
- Edge cases: n = 0, 1, 2 (all → 0); n = 3 (→ 1).
