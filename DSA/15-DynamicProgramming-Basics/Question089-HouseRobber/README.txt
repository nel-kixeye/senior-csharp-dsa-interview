You are a robber. Houses are in a row, each containing some amount of money.
You cannot rob two adjacent houses (alarm triggers).
Given an array of non-negative integers, return the maximum amount you can rob.

Example: { 1, 2, 3, 1 } -> 4  (rob house 1 and 3)

Restrictions:
- Dynamic programming
- O(n) time, O(1) space preferred
- Do not use LINQ
