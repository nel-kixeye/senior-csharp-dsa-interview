Compute the nth Fibonacci number using recursion with memoization.
F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)

Note: Pure recursion without memoization is O(2^n) — not acceptable for a senior interview.
Implement memoization or an iterative recursive approach.

Restrictions:
- Start with the recursive definition
- Add memoization to achieve O(n) time
