Implement a first-in first-out queue using only two stacks.

Implement MyQueue:
- void Push(int x)   pushes element to back of queue
- int Pop()          removes and returns the front element
- int Peek()         returns the front element without removing
- bool Empty()       returns true if the queue is empty

Restrictions:
- Use only two Stack<int> instances
- Do not use Queue<T> or LINQ
- Amortized O(1) per operation
